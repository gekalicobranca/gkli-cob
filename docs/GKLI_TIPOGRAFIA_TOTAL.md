# GKLI Tipografia Total — v1

Aplicado no projeto inteiro:

- Menu lateral com peso visual reduzido: itens em `13px`, `font-normal`, ícones com stroke mais leve.
- Seções do menu com letter spacing menor e contraste suave.
- Usuário + perfil mantidos na mesma linha.
- Botões padronizados com `font-medium` e tracking discreto.
- Cabeçalho de página com título mais leve (`font-medium`) e escala menos agressiva.
- Login sem `next/image fill` para evitar aviso de altura 0 no logo.
- Logo principal em `/public/logo-gkli.png`; símbolo do menu em `/public/logo-gkli-symbol.png`.
- Tokens globais adicionados ao `app/globals.css` para replicação em CRM e Ciclo.

Nome do app mantido como `gkli-cob`.
